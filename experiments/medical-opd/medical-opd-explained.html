01 · 先看结论

完整流程跑通了，评测没有变好

这一章把 Medical SFT、Medical OPD、Base-anchor OPD 串成 SAR 流程。最终 adapter 在本地小评测上没有超过 base：MedQA 9/50 → 8/50，C-Eval 10/40 → 9/40。

−1两道评测集都只少了 1 道题。样本只有 50 和 40 条，这种差异不能单独解释成训练退化。
这是本章最诚实的部分

训练流程完整、每阶段都有真实 backward 和 adapter，但本地 smoke 评测没有给出正向证据。不要把“pipeline completed”改写成“医疗能力提升”。

03 · 符号与公式

同一章里其实有两个完全不同的 loss

Medical SFT 是有监督学习：题目和标准医学回答都已知，只在 completion token 上计算 cross entropy。Medical OPD 与 Base-anchor OPD 则是蒸馏：Student 先采样，Teacher 对同一条轨迹逐 token 打分。

  • pθ(wt)Student 对标准 completion 第 t 个 token 的概率。
  • LSFT只对 completion 位置求平均的 cross entropy；prompt token 被 −100 屏蔽。
  • πS, πMStudent 与 Medical Teacher 的 token 分布。
  • πAAnchor Teacher：原始 Qwen3-1.7B base 的分布，冻结且不挂 adapter。
  • rtKLStudent 与当前 Teacher 在同一 token 上的 logprob 差。
  • At由负 KL 差形成的 token advantage；Medical 和 Anchor 两段方向相同，但目标分布不同。
LSFT = −(1 / |C|) Σt∈C log pθ(wt | x, w<t)
C 是标准医学 completion 的 token 位置集合，x 是医疗问题 prompt。prompt 不参与 loss，避免模型只学会复述题目。
rtKL = log πS(yt) − log πteacher(yt),   At = −β · rtKL
Medical Teacher 想把 Student 拉向医学回答；Anchor Teacher 想把 Student 拉回原始通用分布。两次都用同一个 KL advantage 形式。
LPPO = −meant[ min(ρtAt, clip(ρt, 0.8, 1.2) At) ]
本页的 Medical OPD 与 Anchor OPD 都显式传入 loss_fn="ppo"；ρ 是当前策略相对采样策略的 ratio。
SFT loss 下降不等于医疗准确率上升

SFT 的 token accuracy 是“在见过的训练 completion 上，argmax 猜中下一个 token 的比例”。它衡量拟合，不衡量在 MedQA / C-Eval 上的选择题推理。

04 · 完整训练链路

三段 SAR 到底各自保存了什么

4B baseMedical SFT
→
Medical Teacher4B + 冻结 adapter
→
1.7B StudentMedical OPD
→
Anchor OPD原始 1.7B 当老师
→
最终 adapter90 题本地评测
# Stage 1: 训练医学老师
medical_teacher = Qwen3-4B + LoRA
train only on completion tokens with cross entropy

# Stage 2: 医学蒸馏
student = fresh Qwen3-1.7B + LoRA
for each medical prompt:
    y ~ student
    teacher_logp = medical_teacher.score(prompt + y)
    update student with -reverse_kl advantage + PPO clip

# Stage 3: 分布回拉
for each C-Eval prompt:
    y ~ student
    anchor_logp = frozen Qwen3-1.7B.score(prompt + y)
    update the same student adapter again

save student_anchor_adapter; evaluate base vs final

三段都真实执行并保存了 adapter。这里的“SAR”不是三个模型同时在线，而是顺序训练：Medical Teacher 只服务第二段，第三段换回原始 Student base 做 anchor。

06 · 第二段

Medical OPD 的 KL 非常大

8 个 step 的 reverse KL 均值在 10.16–13.52 之间，均值 12.34，远高于第 05 章的 0.58。一个真实样本可以直接看到原因。

Student 在写“肾结石、血钙、血磷”的推理前缀，Medical Teacher 对这条 1.7B 轨迹给出的概率极低。Teacher 更“专业”不等于它对 Student 的每个前缀都自信。

KL 大不是自动的好信号

它说明两个策略差异很大，也说明训练更新可能很激烈。要判断这种差异是否带来正确能力，仍然需要独立评测。

07 · 第三段

08 · 真实数据手算

同一套 KL 公式，为什么 Medical 比 General 大二十倍？

Medical OPD · step 0

  1. Student 的序列 logprob 总和是 −25.7448，Teacher 是 −1450.9871。
  2. 差值：−25.7448 − (−1450.9871) = +1425.2424。
  3. 这个样本有 128 个 completion token，所以每 token 均值是 1425.2424 / 128 ≈ 11.135。
  4. Medical OPD 8 步的均值范围是 10.1631–13.5202，均值 12.3392，与这个样本同量级。

对比第 05 章同一条轨迹的每 token KL 约 0.68，这里大了十几到二十倍。原因不是公式变了，而是 4B + Medical SFT Teacher 对 1.7B Student 写出的前缀给出了极低概率。

Anchor OPD · step 0 为什么接近 0？

  1. Student 刚结束 Medical OPD，但只在 2-token completion 上被 anchor 评分。
  2. Anchor Teacher 是 Student 的原始 1.7B base，两者在这个极短样本上的分布几乎相同。
  3. 日志 KL 均值是 0.00000828，对应非常小的策略差；随后第 6 步出现 1.613，说明短样本也会被内容强烈影响。

不能把“接近 0”理解成 anchor 永远有效，也不能把某个 step 的负 KL 当成分布距离为负。这里记录的是采样估计，不是完整词表 KL。

10 · 结果边界

不要从这次 run 推出“OPD 无效”

这次实验能确认的是：三段式训练链、两个 Teacher 的切换、adapter 保存和本地选择题评测都真实发生。不能确认的是：Medical OPD 在论文规模下是否有效、SAR 是否普遍优于其他调度、1.7B/4B 的配置能否代表原版。

最值得复读的地方

SFT 训练指标很好，最终评测却没变好。这说明“训练目标在优化”与“目标任务在改善”之间还有一段距离，正是后续实验设计要回答的问题。

11 · 常见疑问

这一章最容易误读的地方

为什么 Medical SFT 的 token accuracy 最后是 93.1%，评测却没有提升？

因为 SFT accuracy 是在当前训练 completion 上预测下一个 token 的命中率，模型可能已经很好地拟合这些文本；MedQA/C-Eval 是换题、换选项后的选择题，需要迁移和推理，目标不同。

为什么 Medical Teacher 是 4B，而 Student 是 1.7B？

这是刻意做跨模型蒸馏：Teacher 容量更大，还经过医学 SFT；Student 更小，目标是学习 Teacher 在医学轨迹上的偏好。两者 tokenizer 必须兼容，否则 token 级 KL 没有意义。

为什么 Medical OPD 的 KL 比第 05 章大一个数量级？

Teacher 从通用 4B 变成了医学 SFT 后的 4B，Student 也从 1.7B 通用模型开始；分布差、回答风格和题目领域都更大，KL 自然会更大。它仍然不是“KL 越大越好”。

Base-anchor OPD 是不是在让模型遗忘医学？

它的目标是把 Student 拉回原始通用分布，缓解 Medical OPD 造成的偏移；但 anchor 的权重、步数和数据选择都会影响结果。这次只跑了 8 步，不能把它当成完整的灾难性遗忘解决方案。

为什么 token 级 KL 均值会出现负数？

日志是在 Student 采样的 token 上估计 KL：log pS−log pT。单个样本当然可能为负；完整分布上的期望 KL 才保证非负。负值不是计算错误，但也不能单独证明方向正确。

MedQA 9/50→8/50 能说明模型退化了吗？

不能稳定地说明。只差一道题，样本只有 50 条；没有置信区间、重复种子或更大评测集。更准确的说法是：这次 smoke 没有观察到提升，并留下了负向信号。
