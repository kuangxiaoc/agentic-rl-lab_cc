01 · 先看结论

完整流程跑通了，评测没有变好

这一章把 Medical SFT、Medical OPD、Base-anchor OPD 串成 SAR 流程。最终 adapter 在本地小评测上没有超过 base：MedQA 9/50 → 8/50，C-Eval 10/40 → 9/40。

−1两道评测集都只少了 1 道题。样本只有 50 和 40 条，这种差异不能单独解释成训练退化。
这是本章最诚实的部分

训练流程完整、每阶段都有真实 backward 和 adapter，但本地 smoke 评测没有给出正向证据。不要把“pipeline completed”改写成“医疗能力提升”。

04 · 第二段

Medical OPD 的 KL 非常大

8 个 step 的 reverse KL 均值在 10.16–13.52 之间，均值 12.34，远高于第 05 章的 0.58。一个真实样本可以直接看到原因。

medical_opd · step 0 · 肾结石题128 token
student Σ logpteacher Σ logpreverse KL Σ每 token
−25.745−1450.987+1425.242+11.135

Student 在写“肾结石、血钙、血磷”的推理前缀，Medical Teacher 对这条 1.7B 轨迹给出的概率极低。Teacher 更“专业”不等于它对 Student 的每个前缀都自信。

KL 大不是自动的好信号

它说明两个策略差异很大，也说明训练更新可能很激烈。要判断这种差异是否带来正确能力，仍然需要独立评测。

05 · 第三段

Base-anchor 的 KL 一开始几乎为 0

第三阶段使用 C-Eval 非医疗题，Teacher 是原始 1.7B base。前几个 step 的 KL 很小，说明 Student 与 anchor 在这些短回答上的分布接近；随后才开始拉开。

token 级 reverse KL 的单个样本可以为负；只有对完整分布取期望，KL 才保证非负。这里的重点是观察流程，不是把负值当成公式失效。

07 · 结果边界

不要从这次 run 推出“OPD 无效”

这次实验能确认的是：三段式训练链、两个 Teacher 的切换、adapter 保存和本地选择题评测都真实发生。不能确认的是：Medical OPD 在论文规模下是否有效、SAR 是否普遍优于其他调度、1.7B/4B 的配置能否代表原版。

最值得复读的地方

SFT 训练指标很好，最终评测却没变好。这说明“训练目标在优化”与“目标任务在改善”之间还有一段距离，正是后续实验设计要回答的问题。
