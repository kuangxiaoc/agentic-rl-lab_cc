01.5 · 数学小抄

公式不是装饰，它们在描述数据怎么流动

如果你对 logprob、advantage、ratio、KL 还不熟，先看 数学小抄。它用一条 4-token 的玩具轨迹解释符号，再告诉你每个符号对应 04–09 的哪一个真实字段。

概率

logprob 越接近 0 越自信

序列 logprob 是 token logprob 相加；它不是准确率。

方向

advantage 正增负减

loss 前的负号只是把“提高概率”改写成“最小化损失”。

稳定性

ratio 先看，再 clip

ratio 衡量新旧策略差多少；clip 防止一步更新过猛。

03 · 每页怎么读

固定四问，不跟着代码跑丢

Q1

信号从哪来？

标签、Teacher logprob、组内 reward，还是同一模型的特权上下文？

Q2

信号落在哪些 token？

整条 completion、单个 marker，还是只训练 assistant action token？

Q3

哪一步真的更新了？

看 train_samples、effective_step 或 updated_trajectories，不要只看 loss。

Q4

这次 run 不能证明什么？

每页末尾都写边界；先承认边界，再谈收获。
