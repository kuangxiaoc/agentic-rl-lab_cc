02 · 概率与 log

logprob 是“模型觉得这个 token 有多自然”

模型先给每个候选 token 一个实数分数，叫 logit。softmax 把分数变成概率：

pi = exp(zi) / Σj exp(zj)
zi 是第 i 个候选的 logit；pi 是归一化后的概率，所有候选加起来等于 1。
p = 0.9

很可能

log p ≈ −0.105。越接近 0，说明模型越不意外。

p = 0.5

一半把握

log p ≈ −0.693。二选一时正好是均匀分布。

p = 0.01

很不可能

log p ≈ −4.605。负得越多，模型越意外。

一条回答的序列 logprob 是每个 token 的 logprob 相加：

log p(y | x) = Σt=1..T log p(yt | x, y<t)
T 是 completion token 数。05 章的 −73.683 就是 256 个 token logprob 的和，不是某一个 token 的概率。
先记住这个读法

logprob 是负数；越接近 0 越自信。比较两个模型时，看的是同一个 token、同一个上下文下谁给出的 logprob 更大，不是看谁的数字“更负得漂亮”。

03 · reward 与 advantage

reward 说“好不好”，advantage 说“相对该不该加”

GRPO/DAPO/GSPO 会为同一道题采样一组回答。reward 只告诉每条回答的绝对结果，组内比较后才变成 advantage：

Ai = ri − mean(r1..G)
G 是组大小。Ai > 0：这条比组内平均好；Ai < 0：比平均差；全组同分时所有人都是 0。

DAPO 的本地实现还会除以组内标准差，让不同题目的梯度尺度更接近：

Ai = (ri − mean(r)) / (std(r) + ε)
ε 是防止除以 0 的小数。std 是样本标准差，衡量组内 reward 的分散程度。

训练目标通常写成“最小化 loss”，所以代码里经常看到负号。直觉上：

advantage希望发生什么loss 的写法
A > 0提高这条轨迹或这些 token 的概率−A × ...，最小化它会推高概率
A < 0降低这条轨迹或这些 token 的概率−A × ...，最小化它会压低概率
A = 0没有相对信号，通常不更新objective 为 0
04 · ratio 与 clip

新旧策略差多少：ratio 和 PPO 的“保守更新”

采样时保存旧策略的 logprob，训练时重新计算当前策略的 logprob，二者相减再取指数：

ρt = exp(log πθ(yt|...) − log πold(yt|...))
ρ > 1：当前策略比采样时更偏爱这个 token；ρ < 1：更不喜欢。ρ = 1 表示没变。

PPO 的 clipped objective 是：

min(ρtAt, clip(ρt, 1−εlow, 1+εhigh)At)
clip 把 ratio 截在区间内。min 让更新采取更保守的一侧，避免一次更新把策略推得太远。
DAPO / PPO

逐 token 一个 ratio

一条 100 token 的回答有 100 个 ratio，每个 token 都可能被单独裁剪。

GSPO

整条回答一个 ratio

先对 token log-ratio 求平均，再 exp；整条回答共享一个 ratio 和一次裁剪。

GSPO 的 3e-4 / 4e-4 不是 ratio 只能在 0.0003 到 0.0004 之间

它是相对 1.0 的偏移：允许区间约为 [0.9997, 1.0004]。因为整条序列的几何平均 ratio 很敏感，所以边界比逐 token PPO 紧得多。

05 · KL 与 OPD

KL 衡量两个分布差多远，reverse KL 用 student 的样本估计

完整分布的 KL 是：

DKL(p || q) = Σz p(z) [log p(z) − log q(z)]
p 和 q 是两个概率分布。对完整词表求和时，KL 一定非负；但它不是“正确率”。

OPD 不遍历整个词表，而是在 student 自己采出的 token 上估计 reverse KL：

rtKL = log πstudent(yt) − log πteacher(yt)
yt 是 student 实际写出的 token。rKL > 0：student 比 teacher 更偏爱它；rKL < 0：teacher 更偏爱它。
At = −β · rtKL
β 控制拉向 teacher 的力度。05/09 的本地实验 β=1，所以 advantage 就是负的 logprob 差。

单个 token 的 KL 估计可以为负，因为它只是从一个分布里采样得到的一个样本；对完整分布取期望后才保证非负。日志里的 reverse_kl_mean 是对当前 batch 的 token 样本求平均，不等于完整 KL。

OPD 的“on-policy”是什么意思

completion 必须由当前 student 采样。teacher 只在 student 已经写出的同一条 token 序列上打分，不会重新生成另一条答案。

06 · 一个手算例子

四个 token，看懂 advantage 的符号

假设某个 completion 只有 4 个 token，student 和 teacher 的 logprob 如下：

tokenstudent logpteacher logpstudent − teacheradvantage = −差值
t1−0.2−0.5+0.3−0.3
t2−1.1−0.4−0.7+0.7
t3−0.6−0.60.00.0
t4−0.8−1.3+0.5−0.5

读法：t2 的 teacher 概率更高，所以 advantage 为正，训练会提高 t2；t1 和 t4 是 student 更偏爱、teacher 不认可，所以会被压低；t3 两边一样，不产生信号。

如果把这 4 个 token 的差值求平均：(0.3 − 0.7 + 0 + 0.5) / 4 = 0.025，均值接近 0，但这不代表每个 token 都没信号。OPD 的关键恰恰是逐 token 的稠密信号。

07 · 回到六章

每章只需要抓住一个公式

04 · DECISION SFT

CE = −log p(correct symbol)

没有 reward、没有 ratio；只在 marker 前一个位置监督固定候选。

05 · GENERAL OPD

At = −(log pS − log pT)

student 采样，teacher 沿同一条轨迹打分，token 级更新。

06 · MEDICAL OPD

同一个 At，换两次 teacher

先 Medical Teacher，再 base anchor；最终看独立评测，不只看 KL。

07 · DAPO

Ai = (ri−mean)/std

组内相对 reward；Dynamic Sampling 丢掉全对/全错组。

08 · GSPO

si = exp(mean log ratio)

整条回答一个 ratio、一次裁剪；reward 仍然是组内相对量。

09 · OPSD

同一个模型，不同上下文

teacher 多看参考解，student 只看题；仍然是 sampled-token KL。

08 · 自检

能回答这五个问题，就够读第二阶段了

  • 为什么 logprob 越接近 0，模型越自信？
  • 为什么 advantage 为正时要提高概率，但 loss 里还要加负号？
  • 为什么 ratio 需要 clip，而 reward 本身不需要 clip？
  • 为什么 token 级 KL 均值可能为负，完整分布的 KL 却不会？
  • 为什么“训练 loss 下降”不能直接推出“测试准确率提高”？
