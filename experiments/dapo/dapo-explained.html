01 · 先看结论

这次实验最响的数字不是 loss，而是 24 个被丢掉的组

最终 run 目标完成 3 次有效更新，却采样了 27 次，跳过 24 个全对或全错的组。Dynamic Sampling 让进入 backward 的组更“有用”，但采样成本并没有消失。

3 / 27有效更新 / 总尝试。也就是说，这次 run 只有 11.1% 的 group 真正进入 optimizer step。
这不是完整 DAPO

最终 run 打开了 Dynamic Sampling 和 Clip-Higher，但 token_level_loss=false、overlong_cache=0。Token Mean 与长度惩罚都没有参与这次实验。

02 · 实验设计

同一套 GRPO 骨架，两个开关真正打开

DAPO 改动最终 run实际效果
Clip-Higher0.8 / 1.28正 advantage 的 ratio 上界比 PPO 更宽
Dynamic Samplingtrue只让混合组进入 backward
Token-level Lossfalse仍按 sample mean 聚合
Soft Overlong0没有长度惩罚

因此这一页分析的是“Dynamic Sampling + Clip-Higher 的真实代价”，不是四项改动的全量消融。模型是 Qwen3-4B QLoRA，数据是 GSM8K，group size 4，上限 512 token。

03 · 数据流

先采一组，再判断这组有没有学习信号

一道 GSM8Kprompt
→
采 4 条±1 reward
→
检查混合组0 < correct < 4
→
标准化 advantage(r − mean) / std
→
PPO updateclip 0.8 / 1.28

如果四条全对或全错，组内 reward 没有差异，advantage 全为 0。Dynamic Sampling 直接跳过这一步，换下一题继续采。

04 · 一个理想混合组

James 写信题：2 条错，2 条对

题目问 James 一年写多少页。模型给出了两种答案：312 和 624。四条 completion 的 reward 是 [−1, +1, −1, +1]，这正好是 Dynamic Sampling 想保留的组。

answer最终 boxedrewardadvantage错误原因
0312−1−0.866漏掉“twice a week”
1624+1+0.866正确
2312−1−0.866同样漏乘 2
3624+1+0.866正确

这就是组内相对信号：不需要一个独立 value model，正确轨迹的 advantage 为正，错误轨迹为负。长度惩罚在这个样本里全是 0，因为 overlong_cache=0。

06 · Clip-Higher

上界从 1.2 放宽到 1.28

PPO  : clamp(ratio, 0.8, 1.2)
DAPO : clamp(ratio, 0.8, 1.28)

ratio = exp(current_logprob - old_logprob)

正 advantage 且 ratio 已经超过 1.2 的 token，在 PPO 里继续提高概率不会带来更多 objective；Clip-Higher 把这段空间放宽。这次 run 记录的是配置，不是 ratio 分布，所以不能从页面推断实际有多少 token 被 1.28 截住。

07 · 工程读法

“丢掉无效组”不是免费的

被丢掉的 24 个组已经完成了 prefill、autoregressive generation、答案抽取和 reward 判定。它们只是没有进入 backward，不代表没有消耗生成时间。

数据质量

effective / attempts

本次是 3/27，说明题目难度与模型能力不匹配很严重。

token 利用

train tokens / rollout tokens

需要同时看被丢弃 completion 的长度，不能只看有效组数。

时间

step seconds

补采和等待长尾回答，可能比一次普通 update 更贵。

08 · 结果边界

这张页面的结论只针对这次配置

这次 run 可以说明：Dynamic Sampling 在 GSM8K + Qwen3-4B 上会大量丢弃退化组，3 次有效更新是真实的 optimizer step。不能说明：完整 DAPO 的四项改动都有效，或者 DAPO 一定优于 GRPO。
