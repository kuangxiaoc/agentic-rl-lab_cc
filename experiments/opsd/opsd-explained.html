01 · 先看结论

同一个模型，换一份 prompt，就变成了老师

OPSD 的 Teacher 不是更大的模型，而是同一个 Qwen3-4B base：Student 只看题目，Teacher 额外看到参考解。Student 先采样，两个 prompt 再对同一条 completion 计算 logprob。

4次真实 optimizer step，每次 1 条 256-token completion。KL 从 0.152 波动到 0.504，再回到 0.235。
这一章的重点是“特权上下文”

Teacher 的能力来自它看到了 Student 看不到的参考解，而不是来自第二份更大的参数。

03 · 两个 prompt

差别只在参考解，不在模型参数

Student prompt

只有题目

Problem: …
Please reason step by step …

Teacher prompt

题目 + 参考解

Problem: …
Reference Solution Begin … End
请理解上面的推理，但不要直接复制。

Teacher 不会重新生成答案。它拿到的是 teacher_prompt + student_completion，只对 Student 已经写出的 token 做一次 forward。

05 · 一条真实轨迹

二次方程题：Teacher 对这条前缀更不自信

第 0 步的题目是 x² − mx + 24 的整数根问题。Student 写了 256 token，Teacher 在同一串 token 上给出更低的总概率。

“We are given a quadratic expression: x² − mx + 24 … We are to find how many different values of m are possible.”

Student 还在列因式对，Teacher 已经带着参考解在看同一段前缀。KL 为正，表示 Student 比 Teacher 更偏爱这些 token，因此 advantage 为负，训练会压低它们。

06 · 四步曲线

KL 不是单调下降

0.362

4 个 step、4 道题、4 条 completion，任何一道题变难都可能把均值拉高。这里的实验价值是“每个 token 都拿到了信号”，不是“KL 已经收敛”。

07 · 信号形态

稠密反馈，但不是无限可靠的老师

优点

每个 token 都有梯度

不用等整条回答结束，也不用组内出现对错混合。

优点

不需要第二个模型

Teacher 只是同一份 base 加参考解，显存和部署都更轻。

风险

参考解不等于正确

Teacher 看到 solution 后仍可能给出错误偏好；KL 只表示差异，不表示真理。

08 · 结果边界

这次 run 没有证明数学能力提高

可以确认：同一 base 的双 prompt、Student 采样、Teacher 同轨迹打分、reverse KL advantage、4 次 optimizer step 都真实发生。不能确认：AIME 或任何独立数学 benchmark 提升，也不能确认 full-vocabulary JSD 的效果。

全部 completion 都是 256 token

4 个 step 的平均 completion 长度都是 256，正好撞上上限。这次比较的是推理前缀上的 token 偏好，不是完整解答。
